# AI CLI Gateway

Install the launcher globally:

```sh
npm install --global ai-cli-gateway
```

The launcher supports these five native targets:

- `darwin-x64` via `ai-cli-gateway-darwin-x64`
- `darwin-arm64` via `ai-cli-gateway-darwin-arm64`
- `linux-x64` via `ai-cli-gateway-linux-x64`
- `linux-arm64` via `ai-cli-gateway-linux-arm64`
- `win32-x64` via `ai-cli-gateway-win32-x64`

Node.js `>=22.14.0` is required. Installation uses npm's host-specific optional dependencies and performs no lifecycle downloads; the public packages define no lifecycle scripts.

# AI CLI Gateway v0.2.2

v0.2.2 improves npm package discovery and verifies the native Windows npm launcher path without changing the gateway runtime or API boundary.

## npm package discovery

The npm search metadata now uses the approved product description: Build AI MVPs with Codex CLI, Claude Code, and Gemini CLI through a local OpenAI Responses-compatible API.

The launcher README now covers install, `ai-cli-gateway init`, `ai-cli-gateway serve`, an OpenAI SDK example, compatibility limits, security, and provenance. The native package pages identify themselves as internal dependencies of the main launcher. The public cohort remains the launcher plus these five native packages:

- `ai-cli-gateway-darwin-x64`
- `ai-cli-gateway-darwin-arm64`
- `ai-cli-gateway-linux-x64`
- `ai-cli-gateway-linux-arm64`
- `ai-cli-gateway-win32-x64`

## Windows npm launcher

The real Windows x86-64 `.exe` is installed with the launcher. The release gate executes it through npm's `.cmd` and PowerShell shims, requires identical version output from both paths, checks invalid-command exit behavior, and confirms that neither invocation mutates the installation.

## Install or update

Install or update to the exact release with Node.js `>=22.14.0`:

```console
npm install --global ai-cli-gateway@0.2.2
ai-cli-gateway version
```

All six public packages have no lifecycle scripts. npm selects the exact host-specific optional dependency without an application-owned download during installation or first execution.

## Compatibility and integrity

Runtime behavior and the focused Responses API-compatible subset are unchanged from `v0.2.1`. The release retains five native targets, checksums in `SHA256SUMS`, an SPDX SBOM, separate GitHub attestations, byte-for-byte identical npm native executables and GitHub Release executables, and npm provenance for all six public packages.

Use the [API and Operations Reference](https://github.com/krkarma777/ai-cli-gateway/blob/v0.2.2/docs/reference.md) for the exact runtime contracts, and the [Security Policy](https://github.com/krkarma777/ai-cli-gateway/blob/v0.2.2/SECURITY.md) for private vulnerability reporting.
